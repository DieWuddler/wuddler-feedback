# Wuddler Feedback

Hier könnt ihr **Fehler melden** und **Ideen vorschlagen** für alles von Die Wuddler:
die Minecraft-Mods (Wuddler One, Wuddler Nature, die Renn-Mods) und die Spiele auf [wuddler.com](https://wuddler.com).

👉 [**Neue Meldung erstellen**](https://github.com/DieWuddler/wuddler-feedback/issues/new/choose)

Bevor du schreibst: Schau kurz in die [offenen Meldungen](https://github.com/DieWuddler/wuddler-feedback/issues), vielleicht hat schon jemand dasselbe gemeldet. Dann reicht ein 👍 darunter.

**Bitte keine persönlichen Daten** (echter Name, Adresse, Alter, Fotos) in Meldungen schreiben. Alles hier ist öffentlich.

Den Quellcode der Mods findest du hier nicht, dieses Repo ist nur für Rückmeldungen da.

---

## English

Report **bugs** and suggest **ideas** for everything by Die Wuddler: the Minecraft mods (Wuddler One, Wuddler Nature, the racing mods) and the games on [wuddler.com](https://wuddler.com).

👉 [**Create a new report**](https://github.com/DieWuddler/wuddler-feedback/issues/new/choose)

Please check the [open reports](https://github.com/DieWuddler/wuddler-feedback/issues) first. If someone already reported the same thing, a 👍 is enough.

**Please don't post personal data** (real name, address, age, photos). Everything here is public.

This repository contains no source code, it is only for feedback.
